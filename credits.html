Crèdits de les fotografies

Les fotografies de cotxes i accessoris d'aquest web provenen de Wikimedia Commons i Flickr i s'utilitzen d'acord amb les seves llicències lliures (CC0, domini públic, CC BY o CC BY-SA). Agraïm a tots els autors la seva feina. Cliqueu a l'enllaç de cada imatge per veure'n la pàgina original i la llicència completa. Les imatges sota llicència CC BY-SA s'han redimensionat i comprimit per al web.

El logotip d'AC Classics Montgrí (logo.png i logo.ico) és un disseny propi de Marc i se n'han reservat tots els drets. Les imatges marcades com a «Imatge no disponible» són fotos pendents de substituir per imatges amb llicència o fotos pròpies dels socis. Les previsualitzacions de la pàgina «Enllaços d'Interès» són captures de pantalla fetes per Marc del web de cada club o recurs enllaçat.
